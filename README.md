# 🎓 CMA Exam QBank — Ngân hàng luyện thi CMA Part 1 & Part 2

- **184 tình huống tự luận (CBQ / Essay):** 965 câu hỏi con có hướng dẫn chấm và bảng tính tự động.
- **54 bộ đề thi thử Mock 100 câu:** Mô phỏng phòng thi Prometric chuẩn thời gian thực.
